# المرحلة الثانية — ربط Neon بالمحتوى المحلي

المراجعة العلمية والأكاديمية مؤجلة بتوجيه المستخدم؛ هذا التقرير يوثق التنفيذ التقني ولا يمنح اعتمادًا سريريًا.

- نشر Function API (الإصدار 3 وقت التنفيذ) في المشروع icy-mode-02911943 والفرع br-steep-moon-b9kxm3uf. بقيت متغيرات الاتصال الخاصة بالخادم موروثة، ولم توضع في Android.
- أضيف GET /v1/snapshot: استعلامات قراءة ضمن REPEATABLE READ، تصفية النشر، مصادر مرتبطة فقط، أقسام وتراكيب متداخلة، وبصمة SHA-256 تتغير مع المحتوى وليس عدد الصفحات فقط. فشل الحد الأقصى لا يعيد نسخة مبتورة.
- أضيف sync_state وترحيل Room 3→4. زر تحديث الصفحات يحفظ التحديث بمعاملة واحدة، ويحذف الصفحات التي سبق امتلاكها سحابيًا عند سحبها، ويترك المفضلة والقراءة والحزم المحلية. علامة Seed تمنع إحياء الصفحات المسحوبة عند إعادة الفتح.
- أضيفت اختبارات تحديث بنفس العدد، وسحب، وعدم تكرار Seed، وفشل معاملة SQLite، ورد جزئي، واختبار فعلي Neon→Retrofit→Room وتنزيل ملفين من الحزمة عبر HTTPS ثم القراءة دون طلب آخر.
- الإضافة 005 قابلة لإعادة التطبيق ولا تحتوي DELETE/UPDATE أو تغيير حالات الأمراض والأدوية. اختُبرت مرتين على الفرع br-blue-sunset-b9i12jus قبل تطبيقها على الفرع المحدد. أضيفت بيانات المشروع الموجودة أصلًا: 11 تركيبًا تشريحيًا و8 أقسام أعضاء و180 قسم مرض (تبقى الأمراض مسودات) وروابط المراجع.
- أضيفت ثلاثة manifests وأربعة ملفات أصول موجودة فعلًا. التنزيل من روابط GitHub مثبتة على commit 58cac1a؛ لا ندعي إنشاء Object Storage. البصمات والأحجام مطابقة للملفات الحالية. تصنيف الحزم تعليمي غير مراجع؛ لا يُستعمل verified الموجود داخل ملفات قديمة كاعتماد للمحتوى المثبت.

## التحقق

اختبارات Node محلية: ثلاث حالات ناجحة لتصفية المراجع، تغير بصمة المحتوى، وسحب/حدود النسخة. الاستدعاء الحي الأول للمسار أعاد 13 جهازًا و10 أعضاء، ثم أُكملت التفاصيل والمراجع باستخدام الإضافة 005. ملف الحزمة البعيد أعاد HTTP200 و3219 بايت وبصمة مطابقة.

نتائج Android والبناء النهائية مرتبطة بطلب الدمج. تشمل إعادة فحص اختبارات العارض والحزم وترحيلات الإصدارات القديمة حتى الإصدار 4. لا يعد فحص Node بديلًا عن اختبار Android أو المراجعة العلمية.

## حدود واضحة

الثلاثة عشر جهازًا متاحة والفهرسة والبحث والتصفح المحلي والعارض والحزم والمزامنة موجودة تقنيًا. عدد الأعضاء والأصول لا يتحول إلى تغطية تشريحية كاملة بمجرد اكتمال البرمجة. الأطالس عالية التفاصيل غير المتاحة لا تُختلق. المحتوى السريري والجرعات تبقى خاضعة لباب النشر والمراجعة. يعمل مسار التحديث القديم برمز مشتق من البصمة مع طلب snapshot كامل عند التغير؛ لا يزعم أنه سجل تغييرات جزئي رتيب.
