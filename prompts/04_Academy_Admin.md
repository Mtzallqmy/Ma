# المرحلة الرابعة: أكاديمية الصيدلة والتعليم والحاسبات والإدارة
المطلوب تنفيذ داخل نفس تطبيق Android ونفس Neon appdb:
- أكاديمية ثنائية اللغة بمسارات: أساسيات الصيدلة، التشريح والفيزيولوجيا، علم الأدوية/الحرائك، الصيدلانيات، علم السموم، الصيدلة السريرية، التداخلات، الممارسة المهنية، والدواء في اليمن والعالم العربي. ابدأ بمحتوى أصيل أو مرخص موثق.
- هيكل Courses/Modules/Lessons/References/Quizzes/Questions/Options/Attempts/Progress/ClinicalCases/Calculators/ContentReviews/Translations/Roles/AuditLogs. ترحيلات SQL تراكمية آمنة وRoom محلي مناسب دون حذف محتوى المرحلة 1–3.
- دروس عملية: محتوى مراجع، صور مع نسب الحقوق، خرائط مفاهيم، نتائج تعلم، أمثلة، اختبارات متعددة الخيارات، تفسيرات الإجابات، كشف التكرار، حفظ الدرجات والاستئناف بدون إنترنت، مزامنة لاحقة بإدارة تعارض.
- حالات تعليمية لا تعطي وصفة لمريض حقيقي؛ أوضح أنها محاكاة. اربط الدواء بالجهاز والمرض والمراجع، مع حالة reviewed/unreviewed.
- حاسبات دقيقة وحدات/تخفيف/تركيز/معدلات/نصف العمر بشكل تعليمي. اختبر المدخلات الصفرية، الوحدات، الحدود، التقريب والأخطاء. الحاسبات المتعلقة بجرعات مرضى حقيقيين تتطلب سياسة علمية ومراجعة مستقلة؛ لا تعرض ناتجًا خطِرًا غير معتمد.
- لوحة تحرير ومراجعة بصلاحيات فعلية server-side: Owner/Reviewer/Editor/ReadOnly، Approval Gate ومنع التصعيد، سجلات Audit، إصدارات ونشر/سحب مضمون، مصدر وترخيص وحقول تاريخ مراجعة، عدم وصول المجهول إلى المسودات.
- واجهة Compose واضحة 100% عربية/إنجليزية RTL مع إمكانية تنزيل المسارات التعليمية بدل حشر كل الأصول الثقيلة في APK. اجعل تنزيلات WorkManager متينة، مع حفظ التقدم والمصادر وتراخيص الأصول.
- تحقق عمليًا: اختبارات SQL وPermissions/RBAC وعدم كشف غير المنشور، unit tests للحاسبات، Compose navigation، Room migration، offline lessons/quizzes، فحوص ذاكرة وأداء وشبكات 2G/3G.
