## 1. نظرة عامة على المشروع
**«دواء وحياة — Dawa & Hayah»** هو تطبيق طبي وصيدلاني وتشريحي تعليمي أصيل لنظام Android مبني بلغة **Kotlin** وواجهة **Jetpack Compose (Material 3)** وفق معمارية **Offline-First** الصارمة. يربط التطبيق بين:
1. **موسوعة أجهزة جسم الإنسان الـ 13 والأعضاء والتراكيب الدقيقة** (بالمصطلحات العربية والإنجليزية واللاتينية المعتمدة وفق معيار *Terminologia Anatomica TA2*).
2. **عارض التشريح التفاعلي ثلاثي الأبعاد (`3D Anatomy Viewer — Local GLB`)** مع دعم تحديد الأجزاء التشريحية (Mesh Picking) وإخفاء الطبقات والشفافية والبديل ثنائي الأبعاد للأجهزة الاقتصادية.
3. **موسوعة الأمراض والفيزيولوجيا المرضية (18 مرضاً بهيكل قياسي A–J)** مرتبطة بتصنيف **WHO ICD-11** مع فصل صارم بين الشرح العلمي، الإرشادات السريرية والعلامات التحذيرية (Red Flags)، والفئات الدوائية التعليمية دون وصفات علاجية غير مراجعة.
4. **مدير حزم المحتوى دون إنترنت (`ContentPackManager`)** المزود بفحص التجزئة التشفيرية `SHA-256` والترقية الذرية للملفات.

- `ai-studio/stage-01-foundation` — المرحلة الأولى: التأسيس المعماري والبيانات المحلية وحزم عدم الاتصال (مكتملة).
